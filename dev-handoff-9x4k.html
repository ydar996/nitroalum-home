Unlisted notes for whoever maintains this site. Not linked publicly; share by URL only.

The Model

This repo is a detached static site on GitHub Pages. It is the public face of NitroAlum for search engines and prospects. The application lives separately at the apex domain and shares no code, backend, or pipeline with this site.

Layout

  • index.html, features.html, get-started.html, about.html: public pages
  • styles.css, brand/, fonts/: shared assets, no build step
  • sitemap.xml, robots.txt, CNAME: SEO and domain plumbing
  • README.md, OWNER-GUIDE.md: the maintenance docs (mirror: readme-9x4k.html)

Hard Rules

  • Never delete CNAME; it binds www.nitroalum.com to Pages.
  • App links are a contract: https://nitroalum.com/ and https://nitroalum.com/sign-up stay on every page.
  • Unique title, description, canonical, one h1 per page. Update sitemap.xml on any add or rename.
  • Keep the JSON-LD block on index.html.
  • No em or en dashes; Title Case with the three letter rule; no made up names.
  • Collaborators get this repo only, never the app repo or servers.

Deploys

Push to main. Pages republishes automatically. There is no CI and nothing to build.
