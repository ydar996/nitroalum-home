Site Readme

Browser friendly mirror of README.md. Unlisted; share by URL only.

Purpose

Static SEO and marketing site for NitroAlum at www.nitroalum.com, hosted on GitHub Pages. Fully detached from the application.

App Links Contract

  • Find Your Group: https://nitroalum.com/ (app front door)
  • Create Your Group: https://nitroalum.com/sign-up
  • Members sign in at their own group address via Find Your Group.

SEO Requirements

  • Unique title and meta description per page; canonical and OG tags; one h1.
  • sitemap.xml lists every public page; update it on every change.
  • JSON-LD SoftwareApplication block stays on index.html.
  • Handoff pages stay noindex and unlinked.

Hosting

GitHub Pages from main root. www.nitroalum.com is a CNAME to ydar996.github.io. Preview locally by opening index.html or running python -m http.server.
